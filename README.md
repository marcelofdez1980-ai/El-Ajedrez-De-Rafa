# El Ajedrez de Rafa

Ajedrez 3D estilo Mario 64 con caballeros de la época antigua: jugá contra la IA (Fácil / Difícil / Hardcore), en 2 jugadores o aprendé paso a paso. Incluye repetición de la última jugada, pantalla completa y 4 estilos de fichas.

Publicado con GitHub Pages. Abrí la página y usá Instalar / Agregar a pantalla de inicio en Chrome o Edge para instalarlo como app.
